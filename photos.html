Photo slots

Every place on the site that can show a photo. Upload a file with the slot's name and it appears by itself. Empty slots show nothing to visitors.

How to add a photo

  1. Pick a slot from the tables below and note its file name, for example soil-water.jpg.
  2. Rename your photo to that name, in lower case. .jpg, .jpeg, .png and .webp all work.
  3. Upload it on GitHub: open the folder assets/photos → Add file → Upload files → drag the photo in → Commit changes.
  4. Wait about a minute and reload this page. The slot changes from “Empty” to “Added”.

Resize photos to about 1600 px wide and under 500 KB so pages stay fast. Landscape photos work best; the site crops them to fit and keeps the centre. For a caption, fill in caption for that slot in _data/photos.yml.
